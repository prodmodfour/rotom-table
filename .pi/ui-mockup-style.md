# Rotom Table visual direction for the mockup rendering worker

- Rotom Table is a living field terminal for a Pokémon Tabletop United campaign: energetic, observant, tactical, slightly playful, and never noisy.
- Preserve the named context: Field Guide is reading-first, Workshop is explicit and compact, and Live Encounter is actor/decision-led.
- Make comprehension precede ornament and make one task or decision visually primary.
- Prefer matte, high-contrast surfaces. Rotom red means brand/committed primary action; electric cyan means focus/selection; amber means pending; mint means accepted success; danger red means actual danger/error.
- Use portrait-led identity, a restrained signal spine, and at most one controlled notch on participant/action/decision surfaces.
- Avoid official-game imitation, generic neon sci-fi styling, universal glass, badge floods, overlay soup, tiny essential text, raw IDs, and colour-only meaning.
