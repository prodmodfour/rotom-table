# Third-party media provenance and attribution

This index records provenance for media retained in the Rotom Table 1.0 source distribution. It is an attribution and audit aid, not a representation that redistribution rights have been established. Exact file counts and content hashes live in [`../data/release-readiness/media-asset-inventory.v1.json`](../data/release-readiness/media-asset-inventory.v1.json).

## Item artwork

- Distributed path: `public/item-sprites/`
- Manifest: [`../data/itemSpriteManifest.json`](../data/itemSpriteManifest.json)
- Source project: [PokéSprite](https://github.com/msikma/pokesprite)
- Source notice: [PokéSprite license](https://github.com/msikma/pokesprite/blob/master/license.md)
- Posture: third-party Pokémon-related artwork; explicit downstream redistribution permission was not established by the release inventory.

## Pokémon sprites and derivatives

- Source paths: `public/sprites/`
- Derived paths: `public/spritesheets/`, `public/profile-sprites/pokemon/`
- Manifests: [`../data/pokemonSpriteManifest.json`](../data/pokemonSpriteManifest.json) and [`../data/pokemonBackSpriteManifest.json`](../data/pokemonBackSpriteManifest.json)
- Source hosts: [Pokémon Database sprite index](https://pokemondb.net/sprites) and [Pokémon Showdown sprite repository notice](https://github.com/smogon/sprites#license)
- Posture: third-party official/community Pokémon artwork; generated crops and sheets remain derivatives of those source images.
