# Move automation Phase 1 audit

This audit records missing canonical moves that look close to Phase 1 and classifies them by the explicit Phase 1 rules. It does not add scripts, remove scripts, change runtime behavior, weaken coverage checks, or count canonical derived data as automated coverage.

Current counts for this audit:

| Count | Value |
| --- | ---: |
| Canonical valid moves | 776 |
| Explicit scripts | 243 |
| Missing scripts | 533 |

The worklist report remains advisory only. A human reviewer must choose the exact move list before any implementation batch, and every automated move must be explicitly reviewed by name in a reviewed family module merged into src/utils/move-automation/registry.ts.
