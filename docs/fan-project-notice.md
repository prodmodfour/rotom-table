It is not affiliated with, endorsed by, sponsored by, or approved by The Pokémon Company, Nintendo, Game Freak, Creatures, or the Pokémon Tabletop United authors or publishers. No project name, notice, attribution, or non-commercial posture should be read as official status.

## What the Rotom Table license covers

The repository `LICENSE` applies only to original Rotom Table application code, project-specific documentation, original visual assets, and original tooling. It does not license Pokémon-related or PTU-related names, images, rules terms, concepts, characters, creatures, sprites, reference text, third-party dependencies, or private campaign data.

The canonical runtime reference data, retained documentary/provenance trees, and third-party sprite collections therefore remain outside that grant. Attribution records provenance; it is not permission or legal clearance.
