# Retired legacy encounter-table fixtures — retained and labelled

**Distribution status:** retained by explicit owner disposition at P13-058 on 2026-08-27.

The four JSON files below this directory are frozen pre-SQLite migration fixtures. They are retained because the reviewed GM Campaign Toolkit migration and footprint evidence binds their paths and bytes.

They are not runtime campaign authority. Current GM encounter tables live in SQLite; adding or editing a JSON file here does not add or change a live campaign table. Production code must not use this directory as fallback data.

Treat this as a potentially private-data-sensitive shape even though it is retained as reviewed migration provenance: never place campaign notes, player information, secrets, or current table exports here.
